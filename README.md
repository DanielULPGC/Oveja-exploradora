# Lola · Un prado para todos

Cuento interactivo para Educación Infantil (5 años) alineado con el Decreto 196/2022, de 13 de octubre, por el que se establece el currículo de la Educación Infantil en Canarias.

Versión publicada: https://danielulpgc.github.io/Oveja-exploradora/

## Estructura
Todos los archivos están en la raíz del repositorio. Las imágenes (`escena-*`, `lola-*`, `bruno-*`, `exploradora-*`) se cargan desde la misma carpeta que `index.html`. Al subir archivos nuevos, conviene mantener esa estructura plana y no crear subcarpetas.

## Uso
Se abre directamente en el navegador; no necesita instalación ni conexión a ningún servicio. El progreso y los registros de observación se guardan solo en el navegador de cada dispositivo.

Detalles de la versión: `README_L33.md`.
